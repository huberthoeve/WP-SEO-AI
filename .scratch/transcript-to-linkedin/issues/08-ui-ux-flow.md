# UI/UX flow: pages, interaction patterns, and history view

Type: grilling
Status: resolved

## Question

What should the user-facing pages and interaction patterns be for this app? Specifically:
- What does the landing page show after sign-in?
- How do users browse and select angles after extraction?
- What is the editing experience before publishing?
- What does the history view show?

## Answer

- **Landing page:** Blank slate with a transcript input (paste/upload box). History is secondary, accessed via navigation.
- **Angle browsing:** Tinder-style swiping — users swipe through extracted angles one at a time, approving or rejecting each one.
- **Post generation:** Approved angles automatically generate full posts in the background.
- **Editing experience:** Users edit posts in a text editor and preview how they'll appear on LinkedIn before publishing.
- **History view:** List of drafted (not yet published) posts, which users can return to at any time to edit further or publish.
