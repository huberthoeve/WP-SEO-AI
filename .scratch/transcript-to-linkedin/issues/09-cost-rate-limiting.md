# Cost and rate-limiting for Claude API usage

Type: grilling
Status: resolved

## Question

Should the app enforce any safeguards or limits around Claude API costs per user, given that the LLM API is a paid service?

## Answer

No per-user limits or quotas. Users bear their own API costs; the app does not restrict usage based on monthly spend, request count, or any threshold. Users implicitly consent to the costs when they use the app.
